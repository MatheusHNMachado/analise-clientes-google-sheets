# Análise de Clientes - Google Sheets

Projeto prático desenvolvido durante meus estudos em Análise de Dados, utilizando Google Sheets para análise de operações financeiras de clientes.

## Objetivo
Automatizar métricas e indicadores a partir de uma base de dados de operações de compra e venda de ações, permitindo identificar padrões e classificar perfis de clientes.

## Funcionalidades
- Contagem de operações de compra e venda
- Soma total das operações
- Média de valores por operação
- Classificação automática de perfil do cliente
- Busca dinâmica por e-mail

## Fórmulas e Recursos Utilizados
- CONT.SES
- SOMASES
- MÉDIASES (AVERAGEIFS)
- SE
- Filtros
- Referências absolutas e relativas

## Ferramentas Utilizadas
- Google Sheets
- Microsoft Excel
- GitHub

## Objetivo Profissional
Projeto desenvolvido com foco em aprimorar conhecimentos em análise de dados, lógica analítica e manipulação de bases de dados.
